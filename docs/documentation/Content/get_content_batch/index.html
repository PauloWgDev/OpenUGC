Get Contents Page

Returns a page of content, with search, filters, pagination and sorting.

Content that was soft deleted doesn't appear in this list.

Endpoint​

  • URL: GET http://<your-domain>/api/v1/content
  • Headers:
    • Authorization: Bearer <token>
  • Query Parameters (all optional):
ParameterDefaultDescription
prompt""Text to search for in the content name. It matches any part of the name and ignores upper and lower case: castle finds "Big Castle" and "castle_v2"
tagsnoneOnly return content that has at least one of these tags. Ignores upper and lower case. Send several as tags=racing&tags=night or tags=racing,night
creatorIdnoneOnly return content uploaded by this user ID
page0Page number, starting at 0
size10Number of items per page
sortcreatedAt,descSort order, as field,direction. See the allowed fields below

You can combine the filters. For example, the newest maps from user 5 with "castle" in the name:

GET /api/v1/content?prompt=castle&tags=maps&creatorId=5&sort=createdAt,desc

Sort fields​

FieldSorts by
createdAtUpload date (default, newest first)
updatedAtLast update date
nameName, alphabetically
versionVersion number
avgRatingAverage rating. Content without ratings always goes last
downloadsCountTotal downloads
latestDownloadsCountDownloads in the last 7 days. Useful for a "trending" list

Any other field returns 400 Bad Request. See Sorting for the format.

The page fields are explained in Pagination.

Content fields​

FieldDescription
contentIdID of the content
creatorId, creatorNameID and username of the user who uploaded it
dataURL to download the file. Needs a token, and each call counts as a download
thumbnailURL of the thumbnail image, public. null if the content has no thumbnail
name, descriptionName and description given on upload
tagsTags of the content, lowercase and in alphabetical order. Empty list if it has none
versionVersion number given on upload
downloadsCountNumber of different users who downloaded it. The same user downloading it twice counts once. See How Downloads Are Counted
latestDownloadsCountHow many of those users downloaded it in the last 7 days
avgRatingAverage rating from 1 to 5. null if nobody rated it yet
createdAt, updatedAtUpload date. Since content can't be edited yet, both are the same

Response Status​

  • 200 OK – Returns a page of content. If nothing matches, content is an empty list
  • 400 Bad Request – Invalid sort field, or a parameter with the wrong type (e.g. creatorId=abc)
  • 403 Forbidden – Invalid or missing token
